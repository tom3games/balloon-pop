# 空中風船割り

https://tom3games.github.io/balloon-pop/

ビルや電柱にワイヤーを掛けて飛び回り、街の空に浮かぶ風船を割りまくる3Dのワイヤーアクション。売り物を割られて怒った風船屋の三兄弟がワイヤーで追ってくる。背中の風船を3つ割られたら終わり。割るたびに少し加速、続けて割るとコンボ、金の風船で背中の風船が戻る。空中しっぽ取り（tail-tag）のクローンから作り替えた。

- 遊ぶ: index.html（ビルドなし。three.js は vendor/）
- 検証: `node verify.mjs`（テスト中は無音）／釣り合い: `node tools/sim.mjs 8`
- 素材の出所: CREDITS.md
